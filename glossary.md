# Web Glossary
## URL: Full addres of web resources
## protocol: Domain contact method
## Domain: the name used to access website
## port: the port used for communication
## Path: it's part of URL identifies the resources or the page you want to access within the website 
## Query String: send additional information 
## Fragment: used to select specific part within a webpage
## DNS: used to convert website name to IP address 
## Hsting: it's where the website or application files operate
